How this works

Each project may declare an interactive dashboard via a dashboard.yaml manifest. Two kinds are recognized:

  • static — files served directly from the project's dashboard/ directory. No process to start. Always available.
  • server — declares a port and start command. Tier-2 will add start/stop control here. Not yet wired.

The hub auto-discovers manifests at <project>/dashboard.yaml or <project>/dashboard/dashboard.yaml. Adding one is the only thing needed for a project to show up here with a dashboard link.
