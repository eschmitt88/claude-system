01The two layers

The system is a framework plus the instances it scaffolds. Only the framework lives in this repo. ~/.claude/ is not a separate checkout — install.sh symlinks the load-bearing directories straight back into ~/claude-system/claude/, so editing either path edits the same file and all of it is versioned here.

03The claude/ tree — the ~/.claude payload

Everything the Claude Code harness loads at ~/.claude/ is one of these. They are the framework's primary surface; the coordinator and dashboard exist to serve them.

CLAUDE.md

Durable principles that apply to every project: where things live (SN850X vs OS drive), the git-as-memory model, the experiment folder contract, end-of-task discipline, runtime discipline (worktrees, subagents), and monitoring of long-running ML jobs. Kept terse; instance CLAUDE.md files refine it.

settings.json

Wires the hooks and status line to harness events, sets permissions, effort level, and theme. The repo tracks a scrubbed settings.example.json; the live file is machine-private.

rules/

evaluation.md (Hidden Consistent Evaluation, opt-in by project shape) and agency.md (how much a project's agents do unasked). Neither loads globally: a skill lists them under respects: and reads them as its first step.

templates/project/

The canonical instance: CLAUDE.md, README.md, budget.yaml, dvc.yaml, NOTES.md, _meta/templates/, and the literature/ concepts/ mocs/ experiments/ raw/ journal/ docs/ skeleton.

04Skills — one SKILL.md contract each

Skills are the user-facing verbs. Each is a markdown contract loaded into context on invocation. Three groups: the experiment loop (linked per project), the literature pipeline, and hygiene/ops. subagent spawns a fresh subagent · HCE respects evaluation.md · auto-commit writes & commits without a confirmation gate.

Experiment loop — ideation → execution → iteration

06Rules & CLAUDE.md — the discipline spec

The prose layers. Anything that must hold without exception lives in a hook or script instead.

CLAUDE.md (durable principles)

Where artifacts live, git-as-memory, the experiment folder contract, end-of-task NOTES.md discipline, worktrees for destructive runs, subagents for high-volume narrow work, and how to monitor multi-hour ML jobs (launch with python -u, poll every 10–30 min, halt on a pattern of 3+ bad epochs).

rules/evaluation.md (HCE)

Hidden Consistent Evaluation prevents the autonomous loop from overfitting its own signal. Four hard clauses: (1) test/ is off-limits during search, including by retrieval; (2) two metric files per experiment — metrics.json (validation, the search signal) vs final_metrics.json (held-out, written once at chain end); (3) comparable experiments share one seeded split; (4) the evaluator is part of the holdout: hashed at chain start, checked against a do-nothing submission, run pristine at the final pass. Opt-in by project shape; /lint is the backstop.

rules/agency.md

Per-project autonomy, set by agency: in budget.yaml. standard proposes and waits. max fetches, ingests, proposes and iterates unasked while the coordinator's verdict permits and the budget ceilings hold. One Confirmation principle decides what pauses: artifact writes commit everywhere; hypothesis selection confirms only under standard.

Two archetypes emerge from the same scaffold: literature-curation projects (large knowledge graph, no splits.yaml; e.g. the agentic-research hub) and ML-experiments projects (HCE on, budget.yaml + DVC + sealed test split; e.g. dotaml-turbo).

10Session lifecycle — how the parts talk

A single session weaves skills, hooks, and the coordinator together:

  1. SessionStart prints the box schedule (running and upcoming jobs, the next GPU-quiet window) and the tail of the project's NOTES.md.
  2. A skill that depends on a framework rule reads it first (respects:). In an agency: max repo it also asks the coordinator for the GO / SLOW / HOLD verdict and sizes its batch to it.
  3. Before a long GPU or multi-core run, the session asks /jobs for a window and launches through the attributed launcher, so the run queues behind production jobs and other sessions can see it. /implement spawns the one subagent of the experiment loop.
  4. Each turn, the Stop hook records token spend and the status line records Anthropic's reported quota %. A systemd timer samples hardware every 30s.
  5. Before compaction, PreCompact reminds the session to persist findings and to quote chat-only standing instructions into the summary.
  6. /wrap writes Did/Findings/Next to NOTES.md; the SessionEnd hook writes the journal and, if the project opts in, commits and pushes what is left.

Division of labour: skills = the agent's verbs · hooks and scripts = what must hold without exception · coordinator = the shared resource truth · dashboard = the human's read-only window.

11Install & operate

git clone git@github.com:eschmitt88/claude-system.git ~/claude-system
cd ~/claude-system && ./install.sh        # idempotent: symlinks + systemd units + backups

install.sh symlinks claude/{skills,hooks,lib,templates} and claude/CLAUDE.md into ~/.claude/ (backing up anything it replaces), seeds a private settings.json from the scrubbed example if none exists, provisions the coordinator and dashboard venvs, and installs the systemd user units. Machine config lives in ~/.claude/.env (copied from .env.example; never overwritten).

systemd user unitrole
claude-hw-poller.service / .timerSamples hardware into state.db every 30s.
claude-dashboard.serviceRuns the FastAPI dashboard on the LAN.
claude-rc-snapshot.timer / claude-rc-restore.service / claude-rc-server.serviceSnapshot live Remote Control sessions, restore them after a reboot, and keep a server up so a phone can start new ones.
claude-job-failed@.serviceOnFailure handler: pushes a notice when a gated job fails.

Because claude/ is symlinked into ~/.claude/, editing either path edits the same file — but always commit from ~/claude-system/ so history stays coherent.

12Conventions that hold everywhere

Git is the memory layer

Every durable fact lives in a tracked file — plain Markdown with flat YAML frontmatter. Auto-memory is a hint, not a home. Recent skills commit directly rather than gating on confirmation, because git revert makes it reversible.

raw/ is immutable

Snapshots of papers, repos, and web captures. The agent reads it; nothing writes to it after ingest. Re-ingest instead of editing.

Storage split

Datasets, checkpoints, venvs, HF cache → SN850X under ~/projects/. ~/.claude/ holds only config, skills, hooks, templates.

End every session with /wrap

Did / Findings / Next in NOTES.md; decisions in docs/decisions/NNNN-*.md. Enforced by skill and SessionEnd hook — not by asking nicely.
